TREMER Input File Format

The TREMER input file is a plain text file that contains all the structural, genetic, and genealogical data required to build the phylogenetic tree. The file is divided into distinct data blocks, each indicated by a specific tag starting with a forward slash (e.g., /MARKERS). Lines beginning with an asterisk (*) are treated as comments and ignored by the parser.

Required Blocks

/MARKERS

This block defines the specific Y-DNA STR markers used in the project. The markers must be listed in the exact sequential order that their values will appear in the /STRDATA block.

/MARKERS
DYS393 DYS390 DYS19 DYS391 DYS385a DYS385b DYS426 DYS388

Optional Blocks

/PROJECT

Sets the global name of the project. This is used to prefix the output HTML and SVG filenames.

/PROJECT
Neely_DNA_Project

/GROUPNUM

Sets the global group number being processed. This is used in titles and filenames (e.g., Group 12).

/GROUPNUM
12

/MODAL

Defines the baseline or "ancestral" STR values for the entire group. This is used as the starting point for calculating mutations down the tree.

/MODAL
13 24 14 11 11 14 12 12

/SNPTREE

Defines the deterministic backbone of the tree based on known SNP mutations. The format allows you to specify parent-child relationships. You can use standard notation (Child Parent) or dot-notation to assign historical dates to the SNPs.

/SNPTREE
A17284 BY17509
A17452.1634 A17284.1597

You can mix these formats within the same /SNPTREE block, and TREMER will merge the overlapping lines into a single, unified tree structure.

/GENDATA

Defines genealogical groups and the kits that belong to them. It maps kits to known historical ancestors. The format uses the Ancestor name (with an optional MRCA date), followed by a list of kit numbers enclosed in parentheses.

/GENDATA
JohnDoe.1800 (123456 234567)
JaneSmith.1850 (345678 456789)

/STRDATA

Contains the raw STR test results for every kit. Each entry begins with the Kit ID, followed by its values for the defined markers. Use N or 0 for missing markers.

/STRDATA
123456  13 24 14 11 11 14 12 12
234567  13 25 14 10 N 14 12 12

/KITDATA

Specifies the known birth year of individual kits. This data is used by the engine to calculate genetic distance and estimate the Time to Most Recent Common Ancestor (TMRCA) for inferred STR branches. The format uses the Kit ID, followed by a period and the four-digit birth year.

/KITDATA
B201693.1950  991341.1951 999290.1950 324852.1956 911337.1950
B1255475.1950 137035.1917

/SNPDATA

Lists the positive (+), negative (-), or untested (?) SNP results for specific kits. The format requires the Kit ID, followed by the specific SNP test results in parentheses.

/SNPDATA
123456 (R-M269+ R-L21+ R-DF13-)
234567 (R-M269+ R-L21?)

/GROUPS

Assigns a descriptive group label to a kit. This label will be printed below the kit ID in the final SVG tree output.

/GROUPS
123456 "Virginia Branch"
234567 "Irish Origins"
