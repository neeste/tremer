# TREMER Samples

This directory contains anonymous sample data to demonstrate how to use TREMER and its utilities.

## Files Provided
- `KitA_YDNA_Doe.csv`, `KitB_YDNA_Smith.csv`, `KitC_YDNA_Jones.csv`, `KitD_YDNA_Brown.csv`: Mock FTDNA-style Y-DNA CSV exports containing 111 STR markers each. The values include a few synthetic mutations to demonstrate phylogenetic branching.
- `merged_strs.txt`: The output generated by running the `tools/strmerge` utility on the above CSV files.
- `project_input.txt`: A sample TREMER input file that combines the merged STR data with some basic mock genealogical and SNP data.

## Try it out
1. Ensure the `strmerge` utility is compiled:
   ```bash
   make strmerge
   ```
2. Merge the raw CSV files to generate the STR input:
   ```bash
   ./strmerge samples/*.csv > samples/merged_strs.txt
   ```
3. Run TREMER on the sample project input:
   ```bash
   ./tremer_rewrite samples/project_input.txt
   ```
4. Check the generated `tree1.txt` file to view the resulting phylogenetic tree!
